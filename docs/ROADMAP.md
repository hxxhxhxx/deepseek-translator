## 1. 兼容 WPS 与小绿鲸英文文献阅读器

### 现状

- 取词顺序：UIA 选区 → 剪贴板（自动 `Ctrl+C`）→ 截图 OCR；
- 应用名单在 `AppCompatibility.cs`，按**进程名**匹配；名单内的应用不做 UIA，直接走剪贴板，划词图标拖选后立即出现；
- 本机已安装（2026-11-04 验证）：WPS 主进程 `wps`；小绿鲸是 Electron，**进程名实际是乱码**（安装包编码问题），因此额外用可执行文件路径 `xljsci` 兜底。

### 计划

**WPS（金山办公）**

- 进程名：`wps`（文字）、`et`（表格）、`wpp`（演示）、`wpspdf`（PDF，若独立进程）；
- 处理方式：全部加入「剪贴板取词」名单；
- 原因：WPS 的 UIA 时好时坏（`GetSelection()` 可能返回整段或空），剪贴板最稳，和 PowerPoint 同类处理。

**小绿鲸英文文献阅读器**

- 已知安装包：`Jianjing.XLJSCI`（NSIS，`xiaolvjing_downloader_setup_*.exe`）；
- 进程名待实测确认，先加入候选：`xiaolvjing`、`xljsci`、`xlj`；
- 处理方式：剪贴板取词；如果它屏蔽 `Ctrl+C`，再评估 UIA 兜底或 OCR。

**兜底：窗口标题关键字**

- 除了进程名，再匹配前台窗口标题包含：`WPS`、`小绿鲸`、`XLJSCI`、`英文文献阅读器`；
- 好处：即使实际 exe 名和预期不同，也能命中；实现成本很低。

**验证矩阵**

| 应用 | 场景 | 期望 |
| --- | --- | --- |
| WPS 文字 | 拖选一段、双击选词 | 出现「译」，点击后译文正确 |
| WPS PDF | 拖选一段 | 同上 |
| WPS 表格/演示 | 拖选单元格文本/文本框 | 同上，失败时提示可手动 Ctrl+C |
| 小绿鲸 | 论文正文拖选、双击选词 | 同上 |
| 小绿鲸 | 笔记/翻译面板内选中 | 不会误把整个面板当选区 |

**风险**

- WPS 复制可能带格式/换行，需要 `TextValidator` 正常化；
- 小绿鲸若用自绘 PDF 且禁用复制，剪贴板会拿不到内容，需要 UIA/OCR 兜底；
- 名单是硬编码，后续新阅读器还要改代码（见第 3 节建议）。

## 2. 浮层上下拉伸 + 字号调整

### 现状

- 浮层：`Width=440`、`SizeToContent=Height`、`MaxHeight=680`；
- 内容区 `BodyScroller` 的 `MaxHeight=500`；
- 只支持左右拖宽（320~960），字号固定：译文 15、原文 12、元信息 10。

### 推荐方案

**字号**

- 新增 `OverlayFontSize`（12~24，默认 15），写进 `settings.json`；
- 浮层底部加 `A−` / `A+` 两个小按钮；`Ctrl+鼠标滚轮` 也可调；
- 译文用 `OverlayFontSize`，原文用 `max(11, size-2)`，元信息保持 10；
- 调整后立即生效并保存，下次翻译沿用。

**上下拉伸**

- 浮层底部加一条 8~10px 的拖拽条（`Thumb`），上下拖动改 **`BodyScroller.MaxHeight`**（240~900），
  不是直接改窗口 `Height`；
- 这样短译文仍然自适应高度，长译文到上限后在浮层内滚动，不会出现大片空白；
- 双击拖拽条恢复默认 500；
- 高度/字号都按当前屏幕工作区 clamp，避免拖出屏幕。

**为什么不用“直接拖窗口高度”**

- `SizeToContent=Height` 与手动 `Height` 混用会跳动；
- 短译文会留空白，且 `PositionNearAnchor` 的重定位逻辑要重写；
- 调 `MaxHeight` 改动小、回归风险低。

### 设置项

```csharp
public double OverlayFontSize { get; set; } = 15;          // 12~24
public double OverlayMaxContentHeight { get; set; } = 500; // 240~900
```

### 回归测试

- 拖动标题栏、左右调宽、流式输出、原文选中、单词详解；
- 字号 12 / 15 / 20 / 24 下的换行、滚动、复制；
- 多显示器/混合 DPI 下不超出屏幕；
- 高度拖动后，新翻译仍按选区定位（除非用户手动拖过浮层）。

## 3. 更好的建议（可选）

1. **设置里加“强制剪贴板取词的应用”列表**：以后遇到新阅读器不用改代码，用户自己填进程名；
2. **大字号快捷模式**：一键 15→20，而不是连续点 `A+`；
3. **按显示器记忆字号/高度**：笔记本和外接屏 DPI 不同时更舒服；
4. **兼容性诊断增强**：诊断面板显示“当前前台进程名 + 窗口标题 + 命中规则”，方便反馈；
5. **WPS/小绿鲸 先装再测**：本机没有这两个软件，代码可以先加名单，但真正验收需要安装后跑一遍验证矩阵。
