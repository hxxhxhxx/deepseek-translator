# 跨页拼接翻译（v1.11.2）

## 使用

1. 在 WPS、PDF 阅读器或网页中选中第一段文字。
2. 点「译」图标右侧的 **小 `+` 角标**；这段文字进入“拼接篮”，**不会调用 API**。角标只有 20px，和「译」之间留 6px 空隙，避免误触。
3. 翻到下一页，选中下一段文字，再点 **`+`**。
4. 拼接篮显示 `N 段 · X 字` 和最近一段预览，可：
   - **撤销最后一段**：删掉刚加错的那段；
   - **清空**：放弃整次拼接；
   - **翻译拼接**：把各段合成一段，只发一次请求。
5. 译文显示在最后一次选区的浮层里；如果开启了固定翻译框，则刷新在固定框里。

## 拼接规则

- 每段先做换行统一和首尾空白清理；
- 英文句子之间补一个空格；
- 中文之间不补空格；
- 页尾连字符自动处理：`inter-\nnational` → `international`；
- 括号、中文标点和常见闭标点前不额外补空格；
- 总长度仍受单次翻译上限 **8000 字符**限制，超限时拒绝加入并提示；
- 每段仍会单独校验是否包含可翻译文字，纯数字/符号段不会进入拼接篮。

## 生命周期与边界

- 拼接篮只保存在内存，退出程序或点「清空」即消失；不跨重启保存。
- 最多 20 段；翻译失败时保留拼接内容，可重试；成功后自动清空。
- 拼接篮是独立置顶小窗，不抢目标应用焦点；固定在屏幕右下角，不随页面滚动消失。
- 取词仍走现有 UIA / 剪贴板路径；如果某个应用（例如受保护的 WPS 文档）自动复制失败，这一段会加不进去，需先解决取词或改用 OCR。
- 选段顺序就是拼接顺序；第一版不提供拖动排序，使用「撤销最后一段」纠正最近的误选。
- 翻译请求只发一次，不会因为暂存而逐段计费。
