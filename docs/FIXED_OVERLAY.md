# 固定翻译框（v1.10.0）

## 使用

1. 打开设置，勾选 **「固定翻译框：拖动后保持位置，新翻译原地刷新」** 并保存。
2. 第一次翻译仍出现在新选区旁。
3. 拖动浮层标题栏到你想放的位置。
4. 之后翻译其他段落时，浮层保持在这个位置，新原文和新译文直接刷新在原框里；上下滚动页面、点击浮层外部都不会关闭它。
5. 点 `×` 或按 `Esc` 结束当前固定；下一次翻译回到新选区旁，再重新固定。

固定位置会跨应用重启记住；如果显示器拔插、分辨率或 DPI 改变导致原位置不可见，会自动收敛到最近的可见工作区。

## 行为细节

- **不是新窗口**：应用一直复用同一个 `OverlayWindow`。普通模式每次 `ShowLoading()` 会把窗口重新按新选区定位，固定模式跳过这一步，所以视觉上不再“旧框消失、新框出现”。
- **自动关闭**：固定模式不启动全局点击/滚轮/键盘关闭监听；`×`、`Esc` 和设置窗口仍是明确操作。
- **旧译文保留**：固定模式下新请求开始时不立即清空译文，标题行显示「正在更新…」；新结果返回后替换旧译文。普通模式仍显示原来的加载面板。
- **位置保存**：拖动或调整宽度后保存窗口左上角的物理像素位置；启动恢复时按当前显示器 DPI 换算并 clamp。
- **关闭语义**：点 `×`/`Esc` 会释放当前固定位置；下一段翻译重新出现在新选区旁。跨重启记忆的是最后一次拖动保存的位置，不会让关闭后的下一段突然从旧位置出现。
- **设置窗口**：从浮层或托盘打开设置时会保留当前位置；保存设置后若固定模式开启，下一段仍可沿用该位置。

## 已知限制

- 固定浮层始终置顶；如果它遮挡正文，拖动它即可。它是一个工作框，不会自动避让新内容。
- 多显示器拔插后，窗口尺寸大于新工作区时会尽量保留左上角并 clamp，必要时内部内容滚动。
- 固定模式不会改变取词、翻译、API 费用或隐私行为；它只改变浮层的位置和关闭策略。
